# 🚗 Motiva Fleet

Sistema web desenvolvido para gerenciamento de veículos de empresas parceiras da Motiva.

---

# 📋 Sobre o Projeto

O **Motiva Fleet** foi criado com o objetivo de facilitar o cadastro e gerenciamento de veículos de forma simples, organizada e intuitiva.

A plataforma permite o cadastro de usuários e veículos, além da visualização e remoção dos veículos cadastrados.

O projeto foi desenvolvido para a **Sprint 1** da disciplina de **Application Development**.

---

# ✨ Funcionalidades

✅ Cadastro de usuários  
✅ Cadastro de veículos  
✅ Listagem dinâmica de veículos  
✅ Exclusão de veículos  
✅ Contador de veículos cadastrados  
✅ Navegação dinâmica pela página  
✅ Interface moderna e responsiva  
✅ Feedback visual para ações do usuário  
✅ Design inspirado em plataformas profissionais
