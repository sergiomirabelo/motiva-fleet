# Motiva Fleet

Sistema web desenvolvido para gerenciamento de veículos de empresas parceiras da Motiva.

## Funcionalidades

- Cadastro de usuários
- Cadastro de veículos
- Listagem de veículos
- Exclusão de veículos
- Contador de veículos
- Navegação dinâmica
- Interface responsiva

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo

Facilitar o controle e gerenciamento de veículos de forma simples, organizada e intuitiva.
